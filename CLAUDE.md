# Марафон BudiValen: $100 → $1 000 000

Публичный трекер покерного марафона Романа (ник BudiValen). Общение с ним только на русском и на «ты». Он не разработчик: правки делает Claude, сам Роман вносит только сессии через сайт.

- Сайт: https://rserbatyh680-arch.github.io/marathon/ (GitHub Pages, ветка `main`, корень)
- Репозиторий: `rserbatyh680-arch/marathon`. Пушить в `main`, после пуша Pages обновляется 1–2 мин, CDN-кэш до 10 мин.

## Файлы
- `index.html`: весь сайт (HTML + CSS + JS в одном файле, без сборки).
- `data.json`: `{settings, sessions}`. Сайт читает его публично. В режиме автора сайт пишет его через GitHub Contents API токеном Романа (fine-grained, Contents: read/write), токен хранится только в его браузере (`localStorage`).
- `avatar.jpg`: фото в шапке. `proof.jpg`, `proof2.jpg`, `proof3.jpg`: пруф цели (галерея по кнопке «Пруф»), личные заметки размыты.

## Модель данных
Сессия: `date, ts, mtt, rooms[6], off, usdt, withdraw, rakeback, buyins, hands, wr (bb/100), note`.
Румы (settings.rooms): GGPoker, Кешбек GG, PokerKing, RedStar, Рум 5, Рум 6. Плюс офф-кошелёк и USDT.

## Логика (согласовано с Романом, не менять без спроса)
- БР = сумма всех румов + офф + USDT.
- Результат сессии = ΔБР + вывод − рейкбек. Выводы и кешбек/рейкбек НЕ влияют на график профита.
- Профит = сумма результатов сессий (игровой). График «График профита» строится только по нему, с нуля.
- ROI = профит сессий с бай-инами / сумма бай-инов. АБИ = бай-ины / турниры.
- Винрейт = средний bb/100, взвешенный по рукам.
- «Путь к 1М»: процент = профит / цель (линейно). Две полоски: «Весь путь до $1M» (пройдено зелёным, остальное без цвета) и «Ближний участок» (градиент зелёный→красный, ромбики ключевых точек, подпись «X% до точки 100k»). Точка «пройдена», если пиковый БР её достигал. Ключевые точки и малые точки (события) редактируются в «Настройках».
- Блок «Выигранные хедз-апы (для подкормки эго)» под шкалой, фиолетовый; цифры в settings.hu, правятся в «Настройках» (сейчас 6 из 6).
- Шапка: рыжая рамка аватара, «BudiValen покоряет планету» белым, цель золотым шрифтом Russo One.

## Проверка правок
Локально открыть `index.html` нельзя как гость (вне github.io сайт работает в режиме автора с localStorage и демо-данными). Для вида с реальными данными подменять запросы к `*.github.io` в Playwright на локальные файлы.
